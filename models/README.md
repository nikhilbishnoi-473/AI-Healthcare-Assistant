# Trained Models Directory

This directory contains serialized Machine Learning model artifacts generated by `src/train_models.py`.

## Saved Artifacts

* `heart_disease_model.pkl`: Contains the best trained classification model, feature scaler, and feature list for Heart Disease prediction.
* `diabetes_model.pkl`: Contains the best trained classification model, feature scaler, and feature list for Diabetes prediction.

Models are serialized using `joblib` and loaded during runtime by `src/prediction.py`.
